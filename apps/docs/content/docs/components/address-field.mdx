## 개요

`AddressField`는 주소를 받는 필드입니다. 첫 줄에는 검색으로 찾은 우편번호·기본 주소를 보여 주는 읽기 전용 입력창과 검색 버튼이, 둘째 줄에는 상세 주소 입력창이 있습니다.

주소 검색은 컴포넌트에 들어 있지 않습니다. 소비자가 `onClickButton`에서 우편번호 서비스 등을 열고, 결과를 `value`의 `zipCode`·`address`로 넘깁니다. 상세 주소를 입력하면 `onChangeValue`가 `detail`만 바뀐 값 전체를 넘깁니다.

## 기본 예시

예시의 버튼은 실제 검색 대신 샘플 주소를 채웁니다.

<Preview>
  <AddressFieldDemo />
</Preview>

```tsx
import { useRef, useState } from 'react';

import { AddressField, type AddressValue } from '@bigmobility/vinyl-ui/field';

export default function AddressFieldExample() {
  const [value, setValue] = useState<AddressValue>({
    zipCode: '',
    address: '',
    detail: '',
  });
  const detailRef = useRef<HTMLInputElement>(null);

  const handleSearch = () => {
    openPostcodeSearch((result) => {
      setValue({
        zipCode: result.zonecode,
        address: result.roadAddress,
        detail: '',
      });
      detailRef.current?.focus();
    });
  };

  return (
    <AddressField
      name="address"
      label="주소"
      ref={detailRef}
      value={value}
      addressPlaceholder="주소 검색을 눌러 주세요"
      detailPlaceholder="상세 주소"
      buttonLabel="주소 검색"
      onChangeValue={({ value: nextValue }) => setValue(nextValue)}
      onClickButton={handleSearch}
    />
  );
}
```

`openPostcodeSearch`는 소비자가 쓰는 주소 검색 서비스를 여는 함수입니다. 검색 결과를 넣은 뒤 `ref`로 상세 주소 칸에 포커스를 옮기면 바로 이어서 입력할 수 있습니다.

## 값이 있을 때

`zipCode`가 있으면 첫 줄에 `(우편번호) 기본 주소` 형태로 보여 줍니다. `zipCode`만 있으면 `(우편번호)`, `zipCode`가 비어 있으면 기본 주소만 보여 줍니다.

이 형식은 고정입니다. 다른 형식(예: `[06236] 서울 …`)이 필요하면 `zipCode`를 비우고 직접 만든 문자열을 `address`로 넘깁니다. 우편번호는 소비자 상태에 따로 보관합니다.

```tsx
<AddressField
  name="address"
  value={{ zipCode: '', address: `[${zipCode}] ${roadAddress}`, detail }}
  buttonLabel="주소 검색"
  onChangeValue={({ value: nextValue }) => setDetail(nextValue.detail)}
  onClickButton={handleSearch}
/>
```

## 에러

`hasError`를 주거나 `errorMessage`를 넘기면 두 입력창이 에러 스타일로 바뀌고 메시지가 보입니다.

<Preview>
  <AddressFieldDemo
    required
    hasError
    errorMessage="주소를 입력해 주세요"
  />
</Preview>

```tsx
<AddressField
  name="address"
  label="주소"
  value={value}
  required
  hasError
  errorMessage="주소를 입력해 주세요"
  buttonLabel="주소 검색"
  onChangeValue={({ value: nextValue }) => setValue(nextValue)}
  onClickButton={handleSearch}
/>
```

## Disabled

## 접근성

- 라벨은 기본 주소 입력창과 연결됩니다. 상세 주소 입력창의 이름은 `detailLabel`(기본 `상세 주소`)입니다.
- 기본 주소 입력창은 `readOnly`라서 직접 입력할 수 없지만 포커스와 읽기는 됩니다.
- 에러 상태면 두 입력창에 `aria-invalid`가 붙고 에러 메시지가 `aria-describedby`로 연결됩니다.
- 컴포넌트는 포커스를 옮기지 않습니다. 검색 결과를 넣은 뒤 `ref`로 상세 주소 칸에 포커스를 옮겨 주세요(기본 예시 참고). 검색 창이 닫힌 뒤 포커스가 사라지지 않고 이어서 입력할 수 있습니다.
- `required`는 라벨의 필수 표시와 기본 주소 칸에만 적용됩니다. 상세 주소가 없는 주소(단독 주택 등)가 있어 상세 주소 칸에는 `required` 속성을 붙이지 않습니다.
- 검색 버튼은 네이티브 `<button type="button">`이라 폼을 제출하지 않고, Tab·Enter·Space로 다룰 수 있습니다. 탭 순서는 기본 주소 → 검색 버튼 → 상세 주소입니다.

## 토큰 커스터마이징

AddressField는 아래 시맨틱 토큰을 참조합니다. ([테마](/docs/theming) 참고).

| 토큰 | 미리보기 | 용도 |

| `layout.bg-light` | <Swatch token="layout.bg-light" /> | 상세 주소 입력 배경 |
| `layout.bg-disable` | <Swatch token="layout.bg-disable" /> | 기본 주소 입력 배경, 비활성 배경 |
| `layout.default-line` | <Swatch token="layout.default-line" /> | 입력 테두리 |
| `layout.strong-line` | <Swatch token="layout.strong-line" /> | 입력 hover·focus 테두리 |
| `layout.bg-issue` | <Swatch token="layout.bg-issue" /> | 에러 배경 |
| `layout.issue-line` | <Swatch token="layout.issue-line" /> | 에러 테두리 |
| `text.input` | <Swatch token="text.input" /> | 라벨·입력 텍스트 |
| `text.input-soft` | <Swatch token="text.input-soft" /> | 플레이스홀더 |
| `text.disable` | <Swatch token="text.disable" /> | 비활성 텍스트 |
| `text.issue` | <Swatch token="text.issue" /> | 에러 메시지 |
| `layout.primary` | <Swatch token="layout.primary" /> | 필수 표시 점 |
| `layout.emphasis` | <Swatch token="layout.emphasis" /> | 버튼 배경 |
| `text.default-light` | <Swatch token="text.default-light" /> | 버튼 텍스트 |
| `layout.highlight-line` | <Swatch token="layout.highlight-line" /> | 버튼 포커스 링 |
