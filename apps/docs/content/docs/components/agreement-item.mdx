체크박스, 약관 문구, 상세 보기 버튼을 한 줄로 묶습니다. 전체 동의와 개별 항목의 연동은 사용하는 쪽에서 상태로 관리합니다.

## 기본 예시

`variant="all"`은 테두리가 있는 전체 동의 항목이고, 기본값 `variant="item"`은 개별 약관 항목입니다. `onDetailClick`을 주면 오른쪽에 상세 보기 버튼이 나타납니다.

전체 동의는 하위 항목의 상태로 계산합니다. 전체 동의를 누르면 `onChangeChecked`에서 하위 항목을 모두 같은 값으로 바꾸고, 하위 항목이 모두 선택되면 전체 동의도 선택됩니다.

```tsx
'use client';

import { useState } from 'react';

import { AgreementItem } from '@bigmobility/vinyl-ui/agreement-item';

const TERMS = [
  { name: 'service', label: '서비스 이용약관 동의' },
  { name: 'privacy', label: '개인정보 수집 및 이용 동의' },
  { name: 'marketing', label: '마케팅 정보 수신 동의' },
];

type AgreementExampleProps = {
  onOpenTerms: (name: string) => void;
};

export default function AgreementExample({ onOpenTerms }: AgreementExampleProps) {
  const [agreed, setAgreed] = useState<Record<string, boolean>>({
    service: false,
    privacy: false,
    marketing: false,
  });

  const allChecked = TERMS.every((term) => agreed[term.name] ?? false);

  const handleChangeAll = ({ value }: { name: string; value: boolean }) => {
    setAgreed(Object.fromEntries(TERMS.map((term) => [term.name, value])));
  };

  const handleChange = ({ name, value }: { name: string; value: boolean }) => {
    setAgreed((prev) => ({ ...prev, [name]: value }));
  };

  return (
    <>
      <AgreementItem
        variant="all"
        name="all"
        checked={allChecked}
        onChangeChecked={handleChangeAll}
      >
        전체 동의
      </AgreementItem>
      {TERMS.map((term) => (
        <AgreementItem
          key={term.name}
          name={term.name}
          checked={agreed[term.name] ?? false}
          onChangeChecked={handleChange}
          onDetailClick={() => onOpenTerms(term.name)}
        >
          {term.label}
        </AgreementItem>
      ))}
    </>
  );
}
```

## 접근성

- 체크박스는 [Checkbox](/docs/components/checkbox#접근성)와 같습니다.
- 상세 보기 버튼은 체크박스와 분리된 `button`이라 눌러도 선택이 바뀌지 않습니다. 이름은 `detailLabel`로 바꿀 수 있습니다.
- 비활성이면 상세 보기 버튼은 포커스되지 않습니다.

## 토큰 커스터마이징

AgreementItem은 아래 시맨틱 토큰을 참조합니다. ([테마](/docs/theming) 참고). 체크박스 색은 [Checkbox](/docs/components/checkbox#토큰-커스터마이징) 토큰을 따릅니다.

| 토큰 | 미리보기 | 용도 |
| --- | --- | --- |
| `layout.default-line` | <Swatch token="layout.default-line" /> | 전체 동의 테두리 |
| `layout.highlight-line` | <Swatch token="layout.highlight-line" /> | 상세 보기 버튼 포커스 링 |
| `text.input` | <Swatch token="text.input" /> | 문구 |
| `text.soft` | <Swatch token="text.soft" /> | 상세 보기 버튼 |
| `text.disable` | <Swatch token="text.disable" /> | 비활성 문구·상세 보기 버튼 |
