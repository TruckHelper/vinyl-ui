import { AppHeader, AppHeaderActions, AppHeaderBackButton, AppHeaderTitle } from '@bigmobility/vinyl-ui/app-header';
import { Icon } from '@bigmobility/vinyl-ui/icon';
import { Link } from '@bigmobility/vinyl-ui/link';

`AppHeader` 안에 `AppHeaderBackButton`(왼쪽), `AppHeaderTitle`(가운데), `AppHeaderActions`(오른쪽)를 필요한 것만 넣어 조합합니다. 넣는 순서와 관계없이 각 파트는 제자리에 놓이고, 제목은 가운데에 맞춰집니다. 제목이 길어 남은 폭을 넘으면 말줄임(…)으로 잘리고, 양쪽 내용의 폭이 크게 다르면 가운데에서 조금 치우칠 수 있습니다. 화면 위에 붙어 있도록 `position: sticky`가 적용되어 있고, 노치가 있는 기기에서는 위쪽·양옆 safe area만큼 안쪽 여백이 늘어납니다.

## 기본 예시

뒤로 가기 버튼과 제목을 함께 씁니다. 뒤로 가기 동작은 `onClick`으로 직접 연결합니다.

<Preview>
  <AppHeader>
    <AppHeaderBackButton />
    <AppHeaderTitle>주문 내역</AppHeaderTitle>
  </AppHeader>
</Preview>

```tsx
'use client';

import { useRouter } from 'next/navigation';

import { AppHeader, AppHeaderBackButton, AppHeaderTitle } from '@bigmobility/vinyl-ui/app-header';

export default function AppHeaderExample() {
  const router = useRouter();

  return (
    <AppHeader>
      <AppHeaderBackButton onClick={() => router.back()} />
      <AppHeaderTitle>주문 내역</AppHeaderTitle>
    </AppHeader>
  );
}
```

### 오른쪽 액션

`AppHeaderActions` 안에 버튼이나 링크를 넣습니다. 여러 개를 넣으면 8px 간격으로 나란히 놓입니다. 아이콘만 있는 요소에는 `aria-label`을 지정합니다.

<Preview>
  <AppHeader>
    <AppHeaderBackButton />
    <AppHeaderTitle>주문 내역</AppHeaderTitle>
    <AppHeaderActions>
      <Link
        href="#오른쪽-액션"
        aria-label="공유"
      ><Icon name="share" /></Link>
    </AppHeaderActions>
  </AppHeader>
</Preview>

```tsx
import { AppHeader, AppHeaderActions, AppHeaderBackButton, AppHeaderTitle } from '@bigmobility/vinyl-ui/app-header';
import { Icon } from '@bigmobility/vinyl-ui/icon';
import { Link } from '@bigmobility/vinyl-ui/link';

<AppHeader>
  <AppHeaderBackButton onClick={handleBack} />
  <AppHeaderTitle>주문 내역</AppHeaderTitle>
  <AppHeaderActions>
    <Link
      href="/orders/share"
      aria-label="공유"
    >
      <Icon name="share" />
    </Link>
  </AppHeaderActions>
</AppHeader>
```

### 메인

첫 화면처럼 로고와 액션을 양끝에 둘 때는 로고 요소를 `AppHeader`에 바로 넣습니다. 파트가 아닌 요소는 왼쪽 칸에 놓이며, 하나만 넣습니다. 여러 개가 필요하면 하나의 요소로 감싸서 넣습니다.

<Preview>
  <AppHeader>
    <Link href="#메인">홈</Link>
    <AppHeaderActions>
      <Link
        href="#메인"
        aria-label="전화 상담"
      ><Icon name="phone" /></Link>
    </AppHeaderActions>
  </AppHeader>
</Preview>

```tsx
<AppHeader>
  <a href="/">
    <img
      src="/logo.svg"
      alt="홈"
    />
  </a>
  <AppHeaderActions>
    <Link
      href="tel:1588-0000"
      aria-label="전화 상담"
    >
      <Icon name="phone" />
    </Link>
  </AppHeaderActions>
</AppHeader>
```

## 뒤로 가기 문구 바꾸기

`AppHeaderBackButton`의 children이 보이는 문구(기본 `뒤로`)이자 스크린 리더가 읽는 이름입니다. 아이콘은 읽히지 않아 보이는 문구와 읽히는 이름이 항상 같습니다.

<Preview>
  <AppHeader>
    <AppHeaderBackButton>이전</AppHeaderBackButton>
  </AppHeader>
</Preview>

```tsx
<AppHeaderBackButton onClick={handleBack}>
  이전
</AppHeaderBackButton>
```

`AppHeader`, `AppHeaderTitle`, `AppHeaderActions`는 각각 `<header>`, `<h1>`, `<div>`의 기본 속성을 그대로 받습니다.

## 접근성

- 루트는 `<header>`라 페이지 최상단에 두면 `banner` 랜드마크로 읽힙니다.
- `AppHeaderTitle`은 `<h1>`이라 화면의 대표 제목으로 읽힙니다. 페이지에 하나만 둡니다. 다이얼로그 안 팝업 헤더로 쓸 때는 페이지의 다른 `<h1>`과 heading이 중복되지 않는지 주의합니다.
- `AppHeaderBackButton`은 네이티브 `<button type="button">`이라 키보드 포커스와 Enter·Space 활성화가 기본 동작합니다. 포커스되면 테두리가 표시됩니다.
- `AppHeaderBackButton`의 이름은 보이는 문구(기본 `뒤로`)입니다. 아이콘은 `aria-hidden`이라 읽히지 않습니다. `aria-label`을 주면 그 값이 그대로 전달되지만, 보이는 문구를 포함하는 값으로 씁니다.
- 아이콘만 있는 액션에는 `aria-label`을 지정합니다.

## 토큰 커스터마이징

AppHeader는 아래 시맨틱 토큰을 참조합니다. ([테마](/docs/theming) 참고).

| 토큰 | 미리보기 | 용도 |
| --- | --- | --- |
| `layout.bg-light` | <Swatch token="layout.bg-light" /> | 헤더 배경 |
| `text.heading` | <Swatch token="text.heading" /> | 제목 |
| `text.default` | <Swatch token="text.default" /> | 뒤로 가기 아이콘·문구 |
| `text.disable` | <Swatch token="text.disable" /> | 뒤로 가기 비활성 |
| `layout.highlight-line` | <Swatch token="layout.highlight-line" /> | 포커스 테두리 |

이 밖에 타이포는 제목 `heading.medium-bold`(글자 크기는 화면 폭과 관계없이 18px), 뒤로 가기 문구 `body.medium-light`를 사용합니다.
