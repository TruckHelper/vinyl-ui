슬라이드 트랙, 화살표, 인디케이터를 파트로 조합합니다. 스크린 리더에는 캐러셀 영역과 슬라이드 그룹으로 읽힙니다.

## 기본 예시

`page`와 `onChangePage`로 현재 슬라이드를 관리하고, `aria-label`로 캐러셀 영역 이름을 지정합니다. `page`는 0부터 시작하고, `onChangePage`는 `{ page }`를 받습니다. 슬라이드 수는 `slideCount`로 지정하고 각 `CarouselItem`과 `CarouselIndicator`에 `index`를 넘깁니다.

<Preview>
  <CarouselDemo />
</Preview>

```tsx
'use client';

import { useState } from 'react';

import {
  Carousel,
  CarouselControl,
  CarouselIndicator,
  CarouselIndicatorGroup,
  CarouselItem,
  CarouselItemGroup,
  CarouselNextTrigger,
  CarouselPrevTrigger,
} from '@bigmobility/vinyl-ui/carousel';

const slides = ['첫 번째 슬라이드', '두 번째 슬라이드', '세 번째 슬라이드', '네 번째 슬라이드', '다섯 번째 슬라이드'];

export default function CarouselExample() {
  const [page, setPage] = useState(0);

  const handleChangePage = ({ page }: { page: number }) => {
    setPage(page);
  };

  return (
    <Carousel
      slideCount={slides.length}
      page={page}
      aria-label="추천 배너"
      onChangePage={handleChangePage}
    >
      <CarouselItemGroup>
        {slides.map((slide, index) => (
          <CarouselItem
            key={slide}
            index={index}
          >
            {slide}
          </CarouselItem>
        ))}
      </CarouselItemGroup>
      <CarouselControl>
        <CarouselPrevTrigger />
        <CarouselIndicatorGroup>
          {slides.map((slide, index) => (
            <CarouselIndicator
              key={slide}
              index={index}
            />
          ))}
        </CarouselIndicatorGroup>
        <CarouselNextTrigger />
      </CarouselControl>
    </Carousel>
  );
}
```

## 카운터

점 대신 `CarouselProgressText`를 넣으면 "현재 / 전체" 형태의 카운터로 표시합니다.

## 반복

`loop`를 주면 마지막 슬라이드에서 다음으로 넘길 때 첫 슬라이드로 돌아갑니다. 지정하지 않으면 첫 슬라이드에서 이전 버튼이, 마지막 슬라이드에서 다음 버튼이 비활성됩니다.

<Preview>
  <CarouselDemo loop />
</Preview>

```tsx
<Carousel
  slideCount={slides.length}
  page={page}
  loop
  aria-label="추천 배너"
  onChangePage={handleChangePage}
>
  ...
</Carousel>
```

## 접근성

- Ark UI `Carousel` 기반입니다. 루트는 `role="region"`과 `aria-roledescription="carousel"`, 각 슬라이드는 `role="group"`과 `aria-roledescription="slide"`로 노출됩니다.
- 캐러셀 영역 이름은 필수 prop인 `aria-label`로 지정합니다. 화면에 보이는 제목이 없어도 스크린 리더가 영역을 구분할 수 있습니다.
- 화살표 버튼은 아이콘만 있으므로 기본 이름 "이전 슬라이드", "다음 슬라이드"를 가집니다. `aria-label`로 바꿀 수 있습니다.
- 점 인디케이터는 "n번 슬라이드로 이동" 이름을 가지고, 현재 슬라이드의 점에 `data-current`가 지정됩니다.
- 점 인디케이터에 포커스가 있을 때 좌우 화살표 키로 이전·다음 슬라이드, Home·End로 처음·마지막 슬라이드로 이동합니다.
- `loop`가 아니면 더 넘길 슬라이드가 없는 쪽 화살표 버튼이 비활성되어 포커스되지 않습니다.

## 토큰 커스터마이징

Carousel은 아래 시맨틱 토큰을 참조합니다. ([테마](/docs/theming) 참고).

| 토큰 | 미리보기 | 용도 |
| --- | --- | --- |
| `layout.primary` | <Swatch token="layout.primary" /> | 현재 점 |
| `layout.bg-soft-gray` | <Swatch token="layout.bg-soft-gray" /> | 나머지 점 |
| `layout.bg-layer` | <Swatch token="layout.bg-layer" /> | 화살표·카운터 배경 |
| `text.default-light` | <Swatch token="text.default-light" /> | 화살표 아이콘·카운터 텍스트 |
| `layout.highlight-line` | <Swatch token="layout.highlight-line" /> | 포커스 링 |
| `layout.bg-disable` | <Swatch token="layout.bg-disable" /> | 비활성 화살표 배경 |
| `text.disable` | <Swatch token="text.disable" /> | 비활성 화살표 아이콘 |

이 밖에 카운터 타이포는 `body.small-light`를 사용합니다.
