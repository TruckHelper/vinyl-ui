`<header>` 요소로 그려지며 스크린 리더에는 배너 랜드마크로 읽힙니다. 로고, 사용자 이름, 구분선, 오른쪽 액션은 파트로 조합합니다. 배경은 투명하고 글자·아이콘은 밝은색(`text.default-light`)이라 어두운 레이아웃 배경 위에 둡니다. 안에 넣은 `Link`도 같은 밝은색을 따릅니다.

## 기본 예시

왼쪽에 `DashboardHeaderLogo`, 오른쪽에 `DashboardHeaderActions`를 둡니다. 두 파트는 양 끝으로 벌어집니다.

<Preview>
  <DashboardHeaderDemo />
</Preview>

```tsx
import {
  DashboardHeader,
  DashboardHeaderActions,
  DashboardHeaderDivider,
  DashboardHeaderLogo,
  DashboardHeaderUser,
} from '@bigmobility/vinyl-ui/dashboard-header';
import { Icon } from '@bigmobility/vinyl-ui/icon';
import { Link } from '@bigmobility/vinyl-ui/link';

export default function DashboardHeaderExample() {
  return (
    <DashboardHeader>
      <DashboardHeaderLogo>
        <a href="/">
          <img
            src="/logo.svg"
            alt="홈"
          />
        </a>
      </DashboardHeaderLogo>
      <DashboardHeaderActions>
        <DashboardHeaderUser>김회원님</DashboardHeaderUser>
        <DashboardHeaderDivider />
        <Link href="/logout">
          로그아웃
          <Icon name="log-out" />
        </Link>
      </DashboardHeaderActions>
    </DashboardHeader>
  );
}
```

## 모바일 메뉴 버튼

태블릿·모바일 화면에서는 오른쪽에 내비게이션을 여닫는 버튼을 둡니다. 닫혀 있으면 `text-align-end`, 열려 있으면 `x` 아이콘을 쓰고, 열림 상태는 `aria-expanded`로 알립니다. 이 화면에서는 사용자 정보 파트(`DashboardHeaderUser`, `DashboardHeaderDivider`)를 쓰지 않습니다.

<Preview>
  <DashboardHeaderMenuDemo />
</Preview>

```tsx
'use client';

import { useState } from 'react';

import { Button } from '@bigmobility/vinyl-ui/button';
import { DashboardHeader, DashboardHeaderActions, DashboardHeaderLogo } from '@bigmobility/vinyl-ui/dashboard-header';

export default function DashboardHeaderMenuExample() {
  const [open, setOpen] = useState(false);

  return (
    <DashboardHeader>
      <DashboardHeaderLogo>
        <a href="/">
          <img
            src="/logo.svg"
            alt="홈"
          />
        </a>
      </DashboardHeaderLogo>
      <DashboardHeaderActions>
        <Button
          variant="emphasis"
          leftIcon={open ? 'x' : 'text-align-end'}
          aria-label={open ? '메뉴 닫기' : '메뉴 열기'}
          aria-expanded={open}
          onClick={() => setOpen(!open)}
        />
      </DashboardHeaderActions>
    </DashboardHeader>
  );
}
```

<Callout type="info">
  아이콘만 있는 버튼 컴포넌트(`IconButton`)가 추가되면 `Button` 대신 넣을 수 있습니다.
</Callout>

## 화면 크기

화면 폭이 1440px 미만이면 상하좌우 16px 여백에 최소 높이 72px, 1440px 이상이면 상하 8px 여백만 두고 최소 높이 56px입니다. 최대 폭과 배경은 정하지 않으므로 필요하면 감싸서 지정합니다.

## 접근성

- 루트가 `<header>`라 배너 랜드마크로 읽힙니다. 한 페이지에 하나만 둡니다.
- `DashboardHeaderDivider`는 `aria-hidden`이 지정되어 스크린 리더에 읽히지 않습니다.
- 헤더 자체는 포커스를 받지 않습니다. 포커스 표시는 안에 넣은 `Link`, `Button`이 그립니다.
- 로고가 이미지면 `alt`에 이동할 곳을 적습니다.

## 토큰 커스터마이징

DashboardHeader는 아래 시맨틱 토큰을 참조합니다. ([테마](/docs/theming) 참고).

| 토큰 | 미리보기 | 용도 |
| --- | --- | --- |
| `text.default-light` | <Swatch token="text.default-light" /> | 글자·아이콘·링크 |
| `layout.highlight-line` | <Swatch token="layout.highlight-line" /> | 구분선(불투명도 40%) |

이 밖에 사용자 이름 타이포는 `body.medium-normal`을 사용합니다.
