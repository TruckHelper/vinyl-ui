title: EmptyState
description: 데이터나 검색 결과가 없을 때 이미지와 안내 문구를 보여 주는 컴포넌트
---

import {
  EmptyState, EmptyStateDescription, EmptyStateImage, EmptyStateTitle,
} from '@bigmobility/vinyl-ui/empty-state';

이미지, 제목, 보조 문구를 파트로 조합합니다. 기본 이미지는 스크린 리더에 읽히지 않습니다.

## 기본 예시

<Preview>
  <EmptyState>
    <EmptyStateImage />
    <EmptyStateTitle>검색 결과가 없어요</EmptyStateTitle>
  </EmptyState>
</Preview>

```tsx
import { EmptyState, EmptyStateImage, EmptyStateTitle } from '@bigmobility/vinyl-ui/empty-state';

export default function EmptyStateExample() {
  return (
    <EmptyState>
      <EmptyStateImage />
      <EmptyStateTitle>검색 결과가 없어요</EmptyStateTitle>
    </EmptyState>
  );
}
```

## 보조 문구

`EmptyStateDescription`을 더하면 제목 아래에 보조 문구가 표시됩니다.

<Preview>
  <EmptyState>
    <EmptyStateImage />
    <EmptyStateTitle>검색 결과가 없어요</EmptyStateTitle>
    <EmptyStateDescription>다른 키워드로 검색해 보세요</EmptyStateDescription>
  </EmptyState>
</Preview>

```tsx
import {
  EmptyState, EmptyStateDescription, EmptyStateImage, EmptyStateTitle,
} from '@bigmobility/vinyl-ui/empty-state';

export default function EmptyStateDescriptionExample() {
  return (
    <EmptyState>
      <EmptyStateImage />
      <EmptyStateTitle>검색 결과가 없어요</EmptyStateTitle>
      <EmptyStateDescription>다른 키워드로 검색해 보세요</EmptyStateDescription>
    </EmptyState>
  );
}
```

## 이미지 변경

`EmptyStateImage` 대신 다른 아이콘을 넣습니다. 크기와 색은 직접 지정합니다.

<Preview>
  <EmptyStateDemo />
</Preview>

```tsx
import { EmptyState, EmptyStateDescription, EmptyStateTitle } from '@bigmobility/vinyl-ui/empty-state';
import { Icon } from '@bigmobility/vinyl-ui/icon';

import { styled } from 'styled-system/jsx';

const EmptyIcon = styled(Icon, {
  base: { fontSize: '8rem', color: 'text.soft' },
});

export default function EmptyStateDemo() {
  return (
    <EmptyState>
      <EmptyIcon name="inbox" />
      <EmptyStateTitle>받은 알림이 없어요</EmptyStateTitle>
      <EmptyStateDescription>새 알림이 오면 여기에 표시돼요</EmptyStateDescription>
    </EmptyState>
  );
}
```
