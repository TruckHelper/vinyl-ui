import { ErrorMessage, Field, Input, Label } from '@bigmobility/vinyl-ui/field';

## 개요

`Field`는 라벨·입력·에러 메시지를 조합하는 오픈 프리미티브입니다. `Field`(Context root)로 감싸고 `Label`·`Input`·`ErrorMessage`를 배치하면,
`Field`가 `id`·에러 상태 등을 context로 각 파트에 전달해 자동으로 연결해 줍니다.

이 프리미티브는 **구조·형태를 직접 조합**해야 할 때 사용합니다.

여러 줄 입력은 `Input` 자리에 `Textarea`를 씁니다([TextareaField](/docs/components/textarea-field) 참고).

각 파트는 `Field` 없이 단독으로도 쓸 수 있으며, 그때는 `id`/`htmlFor` 등을 직접 연결해야 합니다.

## 커스텀 예시

`Field`가 `id`·`hasError`·`required`·`disabled`를 context로 내려주므로, 각 파트는 그 값을 전달 받아 사용이 가능합니다.
만약, 중복해서 `props`를 지정하면 각 파트 컴포넌트의 `props`가 `Field`의 context보다 우선합니다.

<Preview>
  <Field required>
    <Label>이메일</Label>
    <Input placeholder="you@example.com" />
  </Field>
</Preview>

```tsx
import { useState } from 'react';
import { Field, Label, Input, ErrorMessage } from '@bigmobility/vinyl-ui/field';

export default function FieldExample() {
  const [field, setField] = useState({
    email: '',
    error: '',
  });

  const handleChange = ({ name, value }: {
    name: string;
    value: string;
  }) => {
    setField({
      ...field,
      [name]: value,
    });
  };

  return (
    <Field
      hasError={!!field.error}
      required
    >
      <Label>이메일</Label>
      <Input
        name="email"
        value={field.email}
        onChange={handleChange}
      />
      <ErrorMessage>{field.error}</ErrorMessage>
    </Field>
  );
}
```

## 에러 상태

`Field`에 `hasError`를 주면 `Input` 스타일이 바뀌고 `ErrorMessage`가 노출됩니다.

<Preview>

    <Input placeholder="you@example.com" />
    <ErrorMessage>올바른 이메일 형식이 아닙니다</ErrorMessage>
  </Field>
</Preview>

## 접근성

- 라벨 연결 — `Field`가 만든 inputId로 `Label`의 htmlFor와 `Input`의 id가 자동으로 이어집니다.
- 에러 배선 — 에러 상태의 `Input`은 `aria-invalid`와 `aria-describedby`(에러 메시지 id를 가리킴) 속성을 갖습니다.
- 폼 에러 포커스 — 여러 필드 중 가장 위 에러로 이동시키려면, 각 input의 `aria-invalid` 속성을 조회하세요. DOM 순서상 첫 매칭이 최상단입니다.

```tsx
const formRef = useRef<HTMLFormElement>(null);

function focusFirstError() {
  const element = formRef.current?.querySelector('[aria-invalid="true"]');
  element?.focus();
  element?.scrollIntoView({ behavior: 'smooth', block: 'center' });
}
```

- 특정 필드를 직접 제어하려면 `Input`의 `ref`로 input 노드에 접근할 수 있습니다.
- 단독 사용 시에는 `Label`의 htmlFor, `Input`의 id, `ErrorMessage`의 id에 같은 값을 주면 됩니다.
