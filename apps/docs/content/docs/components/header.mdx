`Header`(루트, `<header>`) 안에 `HeaderLogo`(로고), `HeaderMenuTrigger`(모바일 메뉴 버튼), `HeaderNav`(메뉴, `<nav>`), `HeaderActions`(오른쪽 액션)를 이 순서로 넣어 조합합니다. 메뉴 항목은 `HeaderNav` 안에 `HeaderNavLink`로 나열합니다. 모바일 포커스 순서를 위해 `HeaderMenuTrigger`를 `HeaderNav` 앞에 둡니다. 메뉴를 연 뒤 Tab을 누르면 바로 첫 메뉴 항목으로 이동합니다. `HeaderNav`를 `HeaderActions` 앞에 두면 768px 이상에서도 포커스 순서가 화면 순서(로고 → 메뉴 → 액션)와 같습니다.

화면 폭 768px 이상에서는 로고가 왼쪽, 메뉴가 가운데, 액션이 오른쪽에 놓이고 메뉴 버튼은 숨겨집니다. 768px 미만에서는 메뉴가 숨겨지고 오른쪽에 메뉴 버튼이 보입니다. 버튼을 누르면 헤더 아래에 메뉴가 열리고, 메뉴 항목을 누르면 닫힙니다.

<Callout type="info">
  모바일 메뉴 패널의 모양(흰 배경, 안쪽 여백 16px, 항목 간격 16px, 그림자 없음)은 디자인 확정 전 임시 값입니다. 바뀔 수 있습니다.
</Callout>

## 기본 예시

<Preview>
  <HeaderDemo />
</Preview>

```tsx
import { Button } from '@bigmobility/vinyl-ui/button';
import {
  Header,
  HeaderActions,
  HeaderLogo,
  HeaderMenuTrigger,
  HeaderNav,
  HeaderNavLink,
} from '@bigmobility/vinyl-ui/header';

export default function HeaderExample() {
  return (
    <Header>
      <HeaderLogo>
        <a href="/">LOGO</a>
      </HeaderLogo>
      <HeaderMenuTrigger />
      <HeaderNav>
        <HeaderNavLink
          href="/menu1"
          current
        >
          메뉴1
        </HeaderNavLink>
        <HeaderNavLink href="/menu2">메뉴2</HeaderNavLink>
        <HeaderNavLink
          href="/menu3"
          disabled
        >
          메뉴3
        </HeaderNavLink>
      </HeaderNav>
      <HeaderActions>
        <Button variant="neutral">로그인</Button>
      </HeaderActions>
    </Header>
  );
}
```

## 메뉴 항목 상태

- 현재 페이지 항목에는 `current`를 지정합니다. `aria-current="page"`가 붙고 hover와 같은 강조 색으로 표시됩니다.
- `disabled`를 지정하면 클릭해도 이동하지 않습니다. 키보드 포커스도 받지 않습니다.

## 투명 배경

`background="transparent"`를 지정하면 배경이 투명해지고 메뉴 글자가 흰색이 됩니다. 비주얼 영역 위에 헤더를 겹칠 때 씁니다. 모바일에서 메뉴를 열면 배경이 흰색으로 바뀝니다. 스크롤 위치에 따라 흰 배경으로 바꾸려면 `IntersectionObserver` 등으로 감지해 `background`를 바꿉니다. 배경색과 글자색은 부드럽게 전환됩니다.

<Preview>
  <HeaderDemo background="transparent" />
</Preview>

```tsx
<Header background="transparent">
  <HeaderLogo>
    <a href="/">LOGO</a>
  </HeaderLogo>
  <HeaderMenuTrigger />
  <HeaderNav>
    <HeaderNavLink href="/menu1">메뉴1</HeaderNavLink>
    <HeaderNavLink href="/menu2">메뉴2</HeaderNavLink>
    <HeaderNavLink href="/menu3">메뉴3</HeaderNavLink>
  </HeaderNav>
  <HeaderActions>
    <Button variant="neutral">로그인</Button>
  </HeaderActions>
</Header>
```

## 라우터 연동

`HeaderNavLink`에 `asChild`를 지정하면 요소를 만들지 않고 자식 요소에 스타일과 속성을 넘깁니다. Next.js의 `Link` 같은 라우터 링크를 자식으로 넣습니다. 자식은 하나의 요소여야 합니다.

```tsx
import NextLink from 'next/link';

import { HeaderNavLink } from '@bigmobility/vinyl-ui/header';

<HeaderNavLink asChild>
  <NextLink href="/menu1">메뉴1</NextLink>
</HeaderNavLink>
```

`HeaderNavLink`는 `Header` 밖에서도 쓸 수 있습니다. 이때는 메뉴를 닫는 동작만 없습니다.

## 접근성

- 루트는 `<header>`라 배너 랜드마크로, `HeaderNav`는 `<nav>`라 내비게이션 랜드마크로 읽힙니다.
- 메뉴 항목은 네이티브 `<a>`라 키보드 포커스와 Enter 이동이 기본 동작합니다. 현재 페이지는 `aria-current="page"`로 알립니다.
- 메뉴 버튼은 네이티브 `<button>`이며 `aria-expanded`로 열림 상태를, `aria-controls`로 메뉴 영역을 알립니다. Enter·Space로 열고 닫습니다.
- 비활성 항목은 `aria-disabled="true"`와 `tabIndex={-1}`이 지정되어 탭 순서에서 빠집니다.

## 토큰 커스터마이징

Header는 아래 시맨틱 토큰을 참조합니다. ([테마](/docs/theming) 참고).

| 토큰 | 미리보기 | 용도 |
| --- | --- | --- |
| `layout.bg-light` | <Swatch token="layout.bg-light" /> | 흰 배경, 모바일 메뉴 배경 |
| `text.default` | <Swatch token="text.default" /> | 메뉴 글자, 메뉴 버튼 |
| `text.default-light` | <Swatch token="text.default-light" /> | 투명 배경의 메뉴 글자, 메뉴 버튼 |
| `text.accent-primary` | <Swatch token="text.accent-primary" /> | 메뉴 hover·active·현재 페이지 |
| `text.disable` | <Swatch token="text.disable" /> | 비활성 메뉴 |
| `layout.highlight-line` | <Swatch token="layout.highlight-line" /> | 포커스 표시 |

이 밖에 메뉴 글자 타이포는 768px 이상에서 `body.medium-normal`, 768px 미만에서 `body.xlarge-normal`을 사용합니다.
