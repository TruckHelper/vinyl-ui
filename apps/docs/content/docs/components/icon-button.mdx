import { IconButton } from '@bigmobility/vinyl-ui/button';

텍스트 없이 아이콘 하나만 보여 주는 버튼입니다. 보이는 텍스트가 없으므로 `aria-label`로 이름을 반드시 지정합니다.

## 기본 예시

`icon`에 아이콘 이름(lucide)을 넘깁니다. 사용 가능한 이름은 [Lucide 아이콘 목록](https://lucide.dev/icons/)에서 확인하세요.

<Preview>
  <IconButton
    icon="x"
    aria-label="닫기"
  />
  <IconButton
    icon="ellipsis"
    aria-label="더보기"
  />
</Preview>

```tsx
import { IconButton } from '@bigmobility/vinyl-ui/button';

export default function IconButtonExample() {
  return (
    <>
      <IconButton
        icon="x"
        aria-label="닫기"
      />
      <IconButton
        icon="ellipsis"
        aria-label="더보기"
      />
    </>
  );
}
```

## Disabled

네이티브 `disabled` 속성을 그대로 사용합니다.

<Preview>
  <IconButton
    icon="x"
    aria-label="닫기"
    disabled
  />
</Preview>

```tsx
import { IconButton } from '@bigmobility/vinyl-ui/button';

export default function DisabledIconButton() {
  return (
    <IconButton
      icon="x"
      aria-label="닫기"
      disabled
    />
  );
}
```

## 접근성

- 네이티브 `<button>`이라 **키보드 포커스·Enter/Space 활성화·`disabled`** 가 기본 동작합니다.
- 아이콘은 `aria-hidden`이고, 버튼 이름은 `aria-label`로 정해집니다. `aria-label`은 필수입니다.
- `type` 기본값은 `"button"` 입니다.
- 키보드로 포커스하면 `layout.highlight-line` 색 테두리가 보입니다.

## 토큰 커스터마이징

IconButton은 아래 시맨틱 토큰을 참조합니다. ([테마](/docs/theming) 참고).

| 토큰 | 미리보기 | 용도 |
| --- | --- | --- |
| `text.default` | <Swatch token="text.default" /> | 아이콘 기본 색 |
| `text.accent-primary` | <Swatch token="text.accent-primary" /> | hover·active 아이콘 색 |
| `text.disable` | <Swatch token="text.disable" /> | 비활성 아이콘 색 |
| `layout.highlight-line` | <Swatch token="layout.highlight-line" /> | 포커스 테두리 |
