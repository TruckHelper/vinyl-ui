배경을 어둡게 덮고 화면 가운데에 대화상자를 띄웁니다. 헤더, 제목, 부제, 닫기 버튼, 하단 버튼 영역을 파트로 조합합니다. 제목(`ModalTitle`)은 필수입니다. 대화상자의 접근성 이름이 됩니다. 너비는 최대 280px이고 화면 좌우에 16px 여백을 둡니다. 스크린 리더에는 모달 대화상자로 읽힙니다.

## 기본 예시

`open`으로 표시 여부를 관리합니다. 닫기 버튼, Esc 키, 바깥 영역 클릭으로 닫으려 하면 `onClose`가 호출됩니다. `onClose`에서 `open`을 `false`로 바꿉니다. 하단 버튼은 `Button`을 자식으로 넣고 클릭 처리는 버튼에서 합니다.

<Preview>
  <ModalDemo />
</Preview>

```tsx
'use client';

import { useState } from 'react';

import { Button } from '@bigmobility/vinyl-ui/button';
import {
  Modal,
  ModalBottomBtn,
  ModalCloseTrigger,
  ModalHeader,
  ModalTitle,
} from '@bigmobility/vinyl-ui/modal';

export default function ModalExample() {
  const [open, setOpen] = useState(false);

  const handleClose = () => {
    setOpen(false);
  };

  return (
    <>
      <Button
        variant="outline"
        onClick={() => setOpen(true)}
      >
        모달 열기
      </Button>
      <Modal
        open={open}
        onClose={handleClose}
      >
        <ModalHeader>
          <ModalTitle>배송 안내</ModalTitle>
          <ModalCloseTrigger />
        </ModalHeader>
        <ModalBottomBtn>
          <Button
            fit="block"
            onClick={handleClose}
          >
            확인
          </Button>
        </ModalBottomBtn>
      </Modal>
    </>
  );
}
```

## 부제

`ModalDescription`을 넣으면 제목 아래에 부제가 보입니다. 넣지 않으면 제목만 보입니다.

<Preview>
  <ModalDemo
    hasDescription
    label="부제 있는 모달"
  />
</Preview>

```tsx
<ModalHeader>
  <ModalTitle>배송 안내</ModalTitle>
  <ModalDescription>2~3일 내 발송됩니다.</ModalDescription>
  <ModalCloseTrigger />
</ModalHeader>
```

## 반응형 크기

제목과 부제 크기는 화면 너비에 따라 바뀝니다. 768px 미만에서는 제목 `heading.large-bold`(24px), 부제 `body.xlarge-bold`(24px)이고, 768px 이상에서는 제목 `heading.small-bold`(20px), 부제 `body.medium-light`(16px)입니다. 따로 지정할 prop은 없습니다.

## 하단 버튼

`ModalBottomBtn`은 자식 버튼을 같은 너비로 나눠 배치합니다. 버튼이 하나면 `type="single"`(기본값), 두 개면 `type="equal"`을 씁니다.

<Preview>
  <ModalDemo
    type="equal"
    label="버튼 두 개"
  />
</Preview>

```tsx
<ModalHeader>
  <ModalTitle>배송 안내</ModalTitle>
  <ModalCloseTrigger />
</ModalHeader>
<ModalBottomBtn type="equal">
  <Button
    variant="neutral"
    fit="block"
    onClick={handleClose}
  >
    취소
  </Button>
  <Button
    fit="block"
    onClick={handleClose}
  >
    확인
  </Button>
</ModalBottomBtn>
```

## 접근성

- Ark UI `Dialog` 기반으로 `role="dialog"`와 `aria-modal="true"`가 지정됩니다.
- `ModalTitle`은 `aria-labelledby`로, `ModalDescription`은 `aria-describedby`로 대화상자에 연결됩니다. 제목은 필수입니다. 빠지면 대화상자에 이름이 없습니다.
- 열리면 포커스가 대화상자 안으로 들어가고, Tab은 대화상자 안에서만 돕니다. 닫히면 열기 전 포커스가 있던 요소로 돌아갑니다.
- Esc 키와 바깥 영역 클릭으로 `onClose`가 호출됩니다. 열려 있는 동안 페이지 스크롤이 잠깁니다.
- 닫기 버튼은 아이콘만 있으므로 기본 이름 "닫기"를 가집니다. `aria-label`로 바꿀 수 있습니다.

## 토큰 커스터마이징

Modal은 아래 시맨틱 토큰을 참조합니다. ([테마](/docs/theming) 참고).

| 토큰 | 미리보기 | 용도 |
| --- | --- | --- |
| `layout.bg-layer` | <Swatch token="layout.bg-layer" /> | 배경 덮개 |
| `layout.bg-light` | <Swatch token="layout.bg-light" /> | 대화상자, 헤더, 하단 버튼 영역 배경 |
| `layout.highlight-line` | <Swatch token="layout.highlight-line" /> | 닫기 버튼 포커스 링 |
| `text.heading` | <Swatch token="text.heading" /> | 제목 |
| `text.soft` | <Swatch token="text.soft" /> | 부제 |
| `text.default` | <Swatch token="text.default" /> | 닫기 아이콘 |

이 밖에 그림자는 `shadows.toast`, 겹침 순서는 `zIndex.modal`, 타이포는 `heading.large-bold`, `heading.small-bold`, `body.xlarge-bold`, `body.medium-light`를 사용합니다. 버튼 색은 [Button](/docs/components/button)을 따릅니다.
