## 개요

`PasswordField`는 비밀번호 입력에 보기/숨기기 토글을 더한 필드입니다. 라벨, 필수 표시, 에러 메시지는 `TextField`와 같은 Field 구성 요소를 씁니다. 입력 값은 제어 방식으로 받고, 보기 상태는 컴포넌트 안에서 관리합니다.

## 기본 예시

<Preview>
  <PasswordFieldDemo
    name="password"
    label="비밀번호"
    placeholder="비밀번호를 입력하세요"
  />
</Preview>

```tsx
import { useState } from 'react';

import { PasswordField } from '@bigmobility/vinyl-ui/field';

export default function PasswordFieldExample() {
  const [password, setPassword] = useState('');

  const handleChange = ({ value }: {
    name: string;
    value: string;
  }) => {
    setPassword(value);
  };

  return (
    <PasswordField
      name="password"
      label="비밀번호"
      value={password}
      placeholder="비밀번호를 입력하세요"
      onChangeValue={handleChange}
    />
  );
}
```

## 보기 토글

입력창 오른쪽의 눈 아이콘을 누르면 비밀번호가 보이고, 다시 누르면 가려집니다.

<Preview>
  <PasswordFieldDemo
    name="current-password"
    label="비밀번호"
    initialValue="vinyl-ui-1234"
  />
</Preview>

## 에러

`errorMessage`를 전달하면 에러 상태가 되어 입력 스타일이 바뀌고 메시지가 노출됩니다. 메시지 없이 에러 스타일만 필요하면 `hasError`를 줍니다.

<Preview>
  <PasswordFieldDemo
    name="password-error"
    label="비밀번호"
    initialValue="1234"
    errorMessage="8자 이상 입력해 주세요"
  />
</Preview>

```tsx
<PasswordField
  name="password"
  label="비밀번호"
  value={password}
  errorMessage={password.length < 8 ? '8자 이상 입력해 주세요' : undefined}
  onChangeValue={({ value }) => setPassword(value)}
/>
```

## 접근성

- Ark UI `PasswordInput` 기반으로 보기 상태에 따라 입력 `type`이 `password`와 `text` 사이에서 바뀝니다.
- 보기 토글은 `button` 요소이고 `aria-label`(기본 "비밀번호 보기", `toggleLabel`로 변경)과 `aria-pressed`로 현재 상태를 알립니다. `aria-controls`로 입력과 연결됩니다.
- 토글은 탭 순서에 포함되어 Tab으로 이동하고 Space나 Enter로 누를 수 있습니다.
- 폼을 제출하거나 초기화하면 비밀번호가 다시 가려집니다.
- `hasError`나 `errorMessage`를 주면 입력에 `aria-invalid`가 지정되고 `aria-describedby`로 에러 메시지와 연결됩니다.
- `disabled`이면 입력과 토글이 모두 비활성화됩니다.

## 토큰 커스터마이징

PasswordField는 아래 시맨틱 토큰을 참조합니다. ([테마](/docs/theming) 참고).

| 토큰 | 미리보기 | 용도 |
| --- | --- | --- |
| `layout.bg-light` | <Swatch token="layout.bg-light" /> | 기본 배경 |
| `layout.default-line` | <Swatch token="layout.default-line" /> | 기본·비활성 테두리 |
| `layout.strong-line` | <Swatch token="layout.strong-line" /> | hover·포커스 테두리 |
| `layout.bg-issue` | <Swatch token="layout.bg-issue" /> | 에러 배경 |
| `layout.issue-line` | <Swatch token="layout.issue-line" /> | 에러 테두리 |
| `layout.bg-disable` | <Swatch token="layout.bg-disable" /> | 비활성 배경 |
| `layout.primary` | <Swatch token="layout.primary" /> | 필수 표시 점 |
| `layout.highlight-line` | <Swatch token="layout.highlight-line" /> | 토글 포커스 링 |
| `text.input` | <Swatch token="text.input" /> | 라벨·입력 텍스트 |
| `text.input-soft` | <Swatch token="text.input-soft" /> | 플레이스홀더, 보기 토글 아이콘 |
| `text.disable` | <Swatch token="text.disable" /> | 비활성 텍스트 |
| `text.issue` | <Swatch token="text.issue" /> | 에러 메시지 |

이 밖에 타이포는 라벨 `body.medium-light`, 입력·에러 메시지 `input.medium-light`를 사용합니다.
