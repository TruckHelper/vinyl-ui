import { Process, ProcessItem } from '@bigmobility/vinyl-ui/process';

`Process` 안에 `ProcessItem`을 단계 순서대로 나열하고, `Process`의 `current`로 현재 단계 번호를 지정합니다. 단계 상태는 순서에 따라 자동으로 정해집니다. 항목 사이 구분선은 자동으로 그려지고, 구분선이 남는 폭을 나눠 가져 `Process`는 부모 폭을 가득 채웁니다. 클릭할 수 없는 표시용 컴포넌트입니다.

## 기본 예시

`current`는 1부터 셉니다. `current` 단계만 채워진 원으로 보이고, 나머지 단계는 빈 원으로 보입니다. 지정하지 않으면 첫 단계가 현재 단계입니다.

<Preview>
  <Process aria-label="신청 단계">
    <ProcessItem>정보 입력</ProcessItem>
    <ProcessItem>완료</ProcessItem>
  </Process>
</Preview>

```tsx
import { Process, ProcessItem } from '@bigmobility/vinyl-ui/process';

export default function ProcessExample() {
  return (
    <Process aria-label="신청 단계">
      <ProcessItem>정보 입력</ProcessItem>
      <ProcessItem>완료</ProcessItem>
    </Process>
  );
}
```

## 단계 이동

`current`를 상태로 관리하면 진행에 따라 현재 단계가 바뀝니다. 단계 수에 제한은 없습니다.

<Preview>
  <ProcessDemo />
</Preview>

```tsx
'use client';

import { useState } from 'react';

import { Button } from '@bigmobility/vinyl-ui/button';
import { Process, ProcessItem } from '@bigmobility/vinyl-ui/process';

const STEPS = ['정보 입력', '서류 확인', '결제', '완료'];

export default function ProcessStepExample() {
  const [current, setCurrent] = useState(1);

  return (
    <>
      <Process
        current={current}
        aria-label="신청 단계"
      >
        {STEPS.map((step) => (
          <ProcessItem key={step}>{step}</ProcessItem>
        ))}
      </Process>
      <Button
        variant="outline"
        disabled={current === 1}
        onClick={() => setCurrent(current - 1)}
      >
        이전
      </Button>
      <Button
        disabled={current === STEPS.length}
        onClick={() => setCurrent(current + 1)}
      >
        다음
      </Button>
    </>
  );
}
```

## 접근성

- `Process`는 순서 있는 목록(`ol`), `ProcessItem`은 목록 항목(`li`)으로 렌더링되어 스크린 리더가 단계 수와 순서를 읽습니다.
- 현재 단계 항목에는 `aria-current="step"`이 지정됩니다.
- 지난 단계도 다음 단계와 같은 빈 원으로 보입니다. 지난 단계를 구분해야 하면 단계 이름으로 알려 줍니다.
- 원은 장식이라 `aria-hidden`으로 숨기고, 상태는 `aria-current`로만 전달합니다.
- 상호작용이 없어 포커스를 받지 않습니다. 목록 이름은 `aria-label`로 지정합니다.

## 토큰 커스터마이징

Process는 아래 시맨틱 토큰을 참조합니다. ([테마](/docs/theming) 참고).

| 토큰 | 미리보기 | 용도 |
| --- | --- | --- |
| `layout.primary` | <Swatch token="layout.primary" /> | 현재 단계 원 배경 |
| `layout.bg-light` | <Swatch token="layout.bg-light" /> | 지난 단계·다음 단계 원 배경 |
| `layout.default-line` | <Swatch token="layout.default-line" /> | 원 테두리, 항목 사이 구분선 |
| `text.default` | <Swatch token="text.default" /> | 단계 이름 |
