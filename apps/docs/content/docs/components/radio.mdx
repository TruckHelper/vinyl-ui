`RadioGroup` 안에 `Radio`를 나열하고, `Radio` 안에 원(`RadioControl`)과 라벨(`RadioLabel`)을 파트로 조합합니다. 스크린 리더에는 라디오 그룹으로 읽힙니다.

## 기본 예시

`value`와 `onChangeValue`로 선택 상태를 관리합니다.

<Preview>
  <RadioDemo />
</Preview>

```tsx
'use client';

import { useState } from 'react';

import { Radio, RadioControl, RadioGroup, RadioLabel } from '@bigmobility/vinyl-ui/radio';

export default function RadioExample() {
  const [value, setValue] = useState('');

  const handleChange = ({ value }: { name: string; value: string }) => {
    setValue(value);
  };

  return (
    <RadioGroup
      name="choice"
      value={value}
      aria-label="선택 항목"
      onChangeValue={handleChange}
    >
      <Radio value="option1">
        <RadioControl />
        <RadioLabel>선택1</RadioLabel>
      </Radio>
      <Radio value="option2">
        <RadioControl />
        <RadioLabel>선택2</RadioLabel>
      </Radio>
      <Radio value="option3">
        <RadioControl />
        <RadioLabel>선택3</RadioLabel>
      </Radio>
    </RadioGroup>
  );
}
```

## 에러

`RadioGroup`에 `hasError`를 주면 선택되지 않은 원의 테두리가 `layout.issue-line`으로 표시됩니다. 선택된 원은 선택 색을 유지합니다.

<Preview>
  <RadioDemo hasError />
</Preview>

```tsx
<RadioGroup
  name="choice"
  value={value}
  hasError
  aria-label="선택 항목"
  onChangeValue={handleChange}
>
  <Radio value="option1">
    <RadioControl />
    <RadioLabel>선택1</RadioLabel>
  </Radio>
  <Radio value="option2">
    <RadioControl />
    <RadioLabel>선택2</RadioLabel>
  </Radio>
  <Radio value="option3">
    <RadioControl />
    <RadioLabel>선택3</RadioLabel>
  </Radio>
</RadioGroup>
```

### 개별 항목 에러

`Radio`에 `hasError`를 주면 해당 항목에만 오류를 표시합니다. 아래 예시에서는 선택2에 오류가 있습니다.

<Preview>
  <RadioDemo errorValue="option2" />
</Preview>

```tsx
<Radio
  value="option2"
  hasError
>
  <RadioControl />
  <RadioLabel>선택2</RadioLabel>
</Radio>
```

## 접근성

- Ark UI `RadioGroup` 기반으로 각 항목은 네이티브 라디오 입력을 가지며, 그룹은 `radiogroup`으로 읽힙니다.
- 그룹의 모든 라디오가 같은 `name`을 가지므로 Tab으로 그룹에 들어오면 선택된 항목(없으면 첫 항목)에 포커스가 가고, 화살표 키로 이전·다음 항목을 선택합니다.
- 그룹 이름은 `aria-label`로 지정합니다.
- `RadioGroup`의 `hasError`는 그룹과 모든 라디오에, `Radio`의 `hasError`는 해당 라디오에 `aria-invalid`를 지정합니다.
- 비활성 항목은 포커스·선택되지 않습니다.

## 토큰 커스터마이징

Radio는 아래 시맨틱 토큰을 참조합니다. ([테마](/docs/theming) 참고).

| 토큰 | 미리보기 | 용도 |
| --- | --- | --- |
| `layout.default-line` | <Swatch token="layout.default-line" /> | 기본 테두리 |
| `layout.highlight-line` | <Swatch token="layout.highlight-line" /> | 원 hover 테두리, 포커스 링 |
| `layout.primary` | <Swatch token="layout.primary" /> | 선택된 원 테두리 |
| `layout.issue-line` | <Swatch token="layout.issue-line" /> | 오류 원 테두리 |
| `layout.strong-line` | <Swatch token="layout.strong-line" /> | 비활성 상태에서 선택된 원 테두리 |
| `text.disable` | <Swatch token="text.disable" /> | 비활성 원 안쪽 |
| `text.input` | <Swatch token="text.input" /> | 모든 상태의 라벨 |
