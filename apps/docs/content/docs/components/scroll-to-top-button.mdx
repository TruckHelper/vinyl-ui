화면 오른쪽 아래에 고정되는 원형 버튼입니다. 페이지를 일정 거리 이상 내리면 나타나고, 누르면 맨 위로 이동합니다.

## 기본 예시

페이지를 300px 넘게 내리면 오른쪽 아래에 버튼이 나타납니다. 이 페이지를 내려서 확인해 보세요. 스위치를 켜면 비활성 상태를 볼 수 있습니다.

</Preview>

```tsx
'use client';

import { useState } from 'react';

import { ScrollToTopButton } from '@bigmobility/vinyl-ui/floating-action-button';
import { Switch, SwitchControl, SwitchLabel, SwitchThumb } from '@bigmobility/vinyl-ui/switch';

export default function ScrollToTopButtonExample() {
  const [disabled, setDisabled] = useState(false);

  const handleChange = ({ value }: { name: string; value: boolean }) => {
    setDisabled(value);
  };

  return (
    <>
      <Switch
        name="disabled"
        checked={disabled}
        onChangeChecked={handleChange}
      >
        <SwitchControl>
          <SwitchThumb />
        </SwitchControl>
        <SwitchLabel>비활성</SwitchLabel>
      </Switch>
      <ScrollToTopButton disabled={disabled} />
    </>
  );
}
```

## Threshold

`threshold`는 버튼이 나타나는 스크롤 거리(px)입니다. 기본 값은 `300`이며, 스크롤 위치가 이 값보다 크면 나타납니다.

```tsx
import { ScrollToTopButton } from '@bigmobility/vinyl-ui/floating-action-button';

export default function ThresholdExample() {
  return (
    <ScrollToTopButton threshold={800} />
  );
}
```

## Behavior

`behavior`는 맨 위로 이동하는 방식입니다. 기본 값은 `smooth`이며, `instant`나 `auto`를 넘길 수 있습니다. 사용자가 동작 줄이기를 설정했으면 `behavior`와 상관없이 바로 이동합니다.

```tsx
import { ScrollToTopButton } from '@bigmobility/vinyl-ui/floating-action-button';

export default function BehaviorExample() {
  return (
    <ScrollToTopButton behavior="instant" />
  );
}
```

## Disabled

네이티브 `disabled` 속성을 그대로 사용합니다. 기본 예시의 스위치로 확인할 수 있습니다.

```tsx
import { ScrollToTopButton } from '@bigmobility/vinyl-ui/floating-action-button';

export default function DisabledExample() {
  return (
    <ScrollToTopButton disabled />
  );
}
```

## 접근성

- 네이티브 `<button>`이라 **키보드 포커스·Enter/Space 활성화·`disabled`** 가 기본 동작합니다. `type`은 항상 `"button"`입니다.
- 아이콘만 있는 버튼이라 접근성 이름 기본 값은 `"맨 위로 이동"`입니다. `aria-label`로 바꿀 수 있습니다.
- 숨겨진 동안에는 `aria-hidden="true"`와 `tabIndex={-1}`이 지정되어 스크린 리더와 탭 순서에서 빠집니다. 포커스가 있는 채로 숨겨지면 포커스를 해제합니다.
- `onClick`에서 `event.preventDefault()`를 부르면 이동하지 않습니다.

## 토큰 커스터마이징

ScrollToTopButton은 아래 시맨틱 토큰을 참조합니다. ([테마](/docs/theming) 참고).

| 토큰 | 미리보기 | 용도 |
| --- | --- | --- |
| `layout.primary` | <Swatch token="layout.primary" /> | 배경 |
| `layout.primary-dark` | <Swatch token="layout.primary-dark" /> | hover·active 배경 |
| `text.default-light` | <Swatch token="text.default-light" /> | 아이콘 |
| `layout.bg-disable` | <Swatch token="layout.bg-disable" /> | 비활성 배경 |
| `text.disable` | <Swatch token="text.disable" /> | 비활성 아이콘 |
| `layout.highlight-line` | <Swatch token="layout.highlight-line" /> | 포커스 표시 |

이 밖에 그림자는 `floating`, 쌓임 순서는 `sticky`를 사용합니다.
