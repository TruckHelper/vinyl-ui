import { Step, StepItem } from '@bigmobility/vinyl-ui/step';

진행 단계를 번호로 보여 주는 목록입니다. 짧은 진행 표시가 필요하면 Process를 씁니다.

`Step` 안에 `StepItem`을 단계 순서대로 나열해 조합합니다. 번호는 순서대로 자동으로 붙고(`StepItem`의 `step`으로 직접 지정할 수도 있음), 단계 사이 구분선도 `Step`이 그립니다. 표시 전용 컴포넌트라 클릭이나 키보드 동작은 없습니다.

## 기본 예시

각 `StepItem`의 `state`로 단계 상태를 지정합니다. 기본값은 `part`(진행 전)입니다.

<Preview>
  <Step aria-label="신청 단계">
    <StepItem state="current">정보 입력</StepItem>
    <StepItem>서류 첨부</StepItem>
    <StepItem>결제</StepItem>
  </Step>
</Preview>

```tsx
import { Step, StepItem } from '@bigmobility/vinyl-ui/step';

export default function StepExample() {
  return (
    <Step aria-label="신청 단계">
      <StepItem state="current">정보 입력</StepItem>
      <StepItem>서류 첨부</StepItem>
      <StepItem>결제</StepItem>
    </Step>
  );
}
```

## 상태

`part`는 진행 전, `current`는 현재 단계, `complete`는 완료한 단계입니다. 완료한 단계는 번호 대신 체크 아이콘이 보입니다.

<Preview>
  <Step aria-label="신청 단계">
    <StepItem state="complete">정보 입력</StepItem>
    <StepItem state="complete">서류 첨부</StepItem>
    <StepItem state="current">결제</StepItem>
    <StepItem>신청 완료</StepItem>
  </Step>
</Preview>

```tsx
<Step aria-label="신청 단계">
  <StepItem state="complete">정보 입력</StepItem>
  <StepItem state="complete">서류 첨부</StepItem>
  <StepItem state="current">결제</StepItem>
  <StepItem>신청 완료</StepItem>
</Step>
```

## 라벨 숨김

`Step`에 `label={false}`를 주면 번호와 아이콘만 보입니다. 데스크톱은 라벨을 보이고, 태블릿과 모바일은 라벨을 숨기는 용도입니다. 숨긴 라벨은 스크린 리더에는 그대로 읽힙니다. `StepItem`에 `label`을 주면 그 단계만 따로 보이거나 숨길 수 있습니다.

<Preview>
  <Step
    label={false}
    aria-label="신청 단계"
  >
    <StepItem state="complete">정보 입력</StepItem>
    <StepItem state="current">서류 첨부</StepItem>
    <StepItem>결제</StepItem>
  </Step>
</Preview>

```tsx
<Step
  label={false}
  aria-label="신청 단계"
>
  <StepItem state="complete">정보 입력</StepItem>
  <StepItem state="current">서류 첨부</StepItem>
  <StepItem>결제</StepItem>
</Step>
```

## 접근성

- `Step`은 순서 목록(`ol`), `StepItem`은 목록 항목(`li`)으로 렌더링되어 스크린 리더가 단계 수와 순서를 읽습니다.
- 목록 이름은 `aria-label`로 지정합니다.
- `current` 단계에는 `aria-current="step"`이 지정됩니다.
- `complete` 단계에는 스크린 리더용 "완료" 텍스트가 함께 읽힙니다.
- 라벨을 숨겨도 텍스트는 시각적으로만 숨겨져 스크린 리더에는 남습니다.
- 상호작용 요소가 없어 탭 순서에 포함되지 않습니다.

## 토큰 커스터마이징

Step은 아래 시맨틱 토큰을 참조합니다. ([테마](/docs/theming) 참고).

| 토큰 | 미리보기 | 용도 |
| --- | --- | --- |
| `layout.primary` | <Swatch token="layout.primary" /> | 현재 단계 원 배경 |
| `layout.bg-light` | <Swatch token="layout.bg-light" /> | 진행 전 단계 원 배경 |
| `layout.default-line` | <Swatch token="layout.default-line" /> | 진행 전 단계 원 테두리, 단계 사이 구분선 |
| `text.soft` | <Swatch token="text.soft" /> | 진행 전 단계 번호 |
| `text.default-light` | <Swatch token="text.default-light" /> | 현재 단계 번호 |
| `text.accent-primary` | <Swatch token="text.accent-primary" /> | 완료 체크 아이콘 |
| `text.input` | <Swatch token="text.input" /> | 단계 라벨 |

이 밖에 타이포는 번호에 `body.small-light`, 라벨에 `body.medium-light`를 사용합니다.
