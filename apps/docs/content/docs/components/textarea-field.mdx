## 개요

`TextareaField`는 여러 줄을 입력받는 필드입니다. `TextField`와 같은 `Label`·`ErrorMessage`를 쓰고, 입력 부분만 `<textarea>`입니다.
높이는 8rem으로 고정되어 있고, 내용이 넘치면 안에서 스크롤됩니다.

## 기본 예시

`value`와 `onChangeValue`로 값을 관리합니다. `onChangeValue`는 `{ name, value }`를 받습니다.

<Preview>
  <TextareaFieldDemo
    name="memo"
    label="메모"
    placeholder="요청 사항을 입력하세요"
  />
</Preview>

```tsx
'use client';

import { useState } from 'react';

import { TextareaField } from '@bigmobility/vinyl-ui/field';

export default function TextareaFieldExample() {
  const [memo, setMemo] = useState('');

  const handleChange = ({ value }: { name: string; value: string }) => {
    setMemo(value);
  };

  return (
    <TextareaField
      name="memo"
      label="메모"
      value={memo}
      placeholder="요청 사항을 입력하세요"
      onChangeValue={handleChange}
    />
  );
}
```

## 필수

`required`를 주면 라벨 옆에 필수 표시가 붙고 `<textarea>`에 `required` 속성이 들어갑니다.

<Preview>
  <TextareaFieldDemo
    name="reason"
    label="사유"
    placeholder="사유를 입력하세요"
    required
  />
</Preview>

```tsx
<TextareaField
  name="reason"
  label="사유"
  value={reason}
  placeholder="사유를 입력하세요"
  required
  onChangeValue={handleChange}
/>
```

## 에러

`errorMessage`를 주면 에러 상태가 되고 메시지가 나옵니다. 메시지 없이 에러 스타일만 보여 줄 때는 `hasError`를 씁니다.

<Preview>
  <TextareaFieldDemo
    name="memo"
    label="메모"
    initialValue="입력한 내용"
    errorMessage="메모를 다시 확인해 주세요"
  />
  <TextareaFieldDemo
    name="note"
    label="비고"
    initialValue="입력한 내용"
    hasError
  />
</Preview>

```tsx
<TextareaField
  name="memo"
  label="메모"
  value={memo}
  errorMessage="메모를 다시 확인해 주세요"
  onChangeValue={handleChange}
/>
<TextareaField
  name="note"
  label="비고"
  value={note}
  hasError
  onChangeValue={handleChange}
/>
```

## 직접 조합하기

`Field` 안에서 `Textarea`를 쓰면 `Input`과 같은 방식으로 라벨·에러가 연결됩니다. [Field](/docs/components/field) 참고.

```tsx
import { ErrorMessage, Field, Label, Textarea } from '@bigmobility/vinyl-ui/field';

<Field hasError={!!error}>
  <Label>메모</Label>
  <Textarea
    name="memo"
    value={memo}
    onChange={(event) => setMemo(event.target.value)}
  />
  <ErrorMessage>{error}</ErrorMessage>
</Field>
```

## 접근성

- 라벨과 `<textarea>`가 `htmlFor`·`id`로 연결되어 스크린 리더가 라벨을 읽습니다.
- 에러 상태에서는 `aria-invalid`가 붙고, 메시지가 있으면 `aria-describedby`가 메시지를 가리킵니다. 메시지는 `role="alert"`로 바로 읽힙니다.
- Enter는 줄바꿈입니다. 폼을 제출하지 않습니다.
