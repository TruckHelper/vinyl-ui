## 개요

`UnitField`는 라벨·입력·에러 메시지에 단위(`unit`)와 아이콘(`icon`)을 더해 완성된 형태로 제공되는 컴포넌트입니다.

[`TextField`](/docs/components/text-field)와 사용법·Props·동작이 동일하며, `unit`·`icon`만 추가됩니다. 단위와 아이콘은 입력값 오른쪽에 표시되며, 둘 다 전달하면 입력값 → 단위 → 아이콘 순서로 배치됩니다.

## 기본 예시

<Preview>
  <UnitFieldDemo
    name="weight"
    label="적재 중량"
    unit="kg"
    placeholder="0"
    required
  />
</Preview>

```tsx
import { useState } from 'react';

import { UnitField } from '@bigmobility/vinyl-ui/field';

export default function UnitFieldExample() {
  const [field, setField] = useState({
    weight: '',
    error: '',
  });

  const handleChange = ({ name, value }: {
    name: string;
    value: string;
  }) => {
    setField({
      ...field,
      [name]: value,
    });
  }

  return (
    <UnitField
      name="weight"
      label="적재 중량"
      value={field.weight}
      unit="kg"
      placeholder="0"
      required
      errorMessage={field.error}
      onChangeField={handleChange}
    />
  );
}
```

## 에러

`errorMessage`를 전달하면 에러 상태가 되어 입력 스타일이 바뀌고 메시지가 노출됩니다.
