## 개요

`VerificationCodeField`는 문자·메일로 받은 인증번호를 입력하는 필드입니다. 입력창 오른쪽에 남은 시간을, 입력창 옆에 재전송·확인 같은 버튼을 둡니다. 숫자 코드용 필드라 입력창은 `inputMode="numeric"`입니다.

남은 시간은 컴포넌트가 세지 않습니다. 소비자가 타이머를 돌리고 `"02:59"` 같은 문자열을 `remainingTime`으로 넘깁니다.

## 기본 예시

<Preview>
  <VerificationCodeFieldDemo />
</Preview>

```tsx
import { useEffect, useState } from 'react';

import { VerificationCodeField } from '@bigmobility/vinyl-ui/field';

const LIMIT_SECONDS = 180;

function formatTime(seconds: number) {
  const minutes = String(Math.floor(seconds / 60)).padStart(2, '0');
  const rest = String(seconds % 60).padStart(2, '0');

  return `${minutes}:${rest}`;
}

export default function VerificationCodeFieldExample() {
  const [code, setCode] = useState('');
  const [seconds, setSeconds] = useState(LIMIT_SECONDS);

  useEffect(() => {
    if (seconds <= 0) {
      return undefined;
    }

    const timer = setTimeout(() => setSeconds(seconds - 1), 1000);

    return () => clearTimeout(timer);
  }, [seconds]);

  return (
    <VerificationCodeField
      name="code"
      label="인증번호"
      value={code}
      placeholder="인증번호 6자리"
      maxLength={6}
      buttonLabel="재전송"
      remainingTime={formatTime(seconds)}
      onChangeValue={({ value }) => setCode(value)}
      onClickButton={() => setSeconds(LIMIT_SECONDS)}
    />
  );
}
```

## 에러

`errorMessage`를 주면 에러 상태가 되어 입력 스타일이 바뀌고 문구가 보입니다. 문구 없이 스타일만 바꾸려면 `hasError`를 줍니다.

## 접근성

- 입력창은 `inputMode="numeric"`, `autoComplete="one-time-code"`라서 모바일에서 숫자 키패드와 문자 인증번호 자동 채우기가 뜹니다.
- 남은 시간은 `role="timer"`로 표시하고 입력창의 `aria-describedby`에 연결합니다. 화면에 안 보이는 "남은 시간" 접두어가 붙어 "남은 시간 02:59"로 읽히고, 매초 읽어 주지는 않습니다.
- 시간 만료는 컴포넌트가 알리지 않습니다. 소비자가 `errorMessage`(예: "입력 시간이 지났습니다")로 알립니다.
- 에러 상태이면 입력창에 `aria-invalid`가 붙고 에러 메시지도 `aria-describedby`에 연결됩니다.
- 버튼은 네이티브 `<button type="button">`이라 폼을 제출하지 않고, Tab·Enter·Space로 다룰 수 있습니다.

| `layout.issue-line` | <Swatch token="layout.issue-line" /> | 에러 테두리 |
| `layout.bg-disable` | <Swatch token="layout.bg-disable" /> | 비활성 배경 |
| `text.input` | <Swatch token="text.input" /> | 라벨·입력 텍스트 |
| `text.input-soft` | <Swatch token="text.input-soft" /> | 플레이스홀더 |
| `text.accent-primary` | <Swatch token="text.accent-primary" /> | 남은 시간 |
