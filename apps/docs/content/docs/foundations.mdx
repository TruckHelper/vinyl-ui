컴포넌트는 컬러를 **시맨틱 토큰**(`layout.*`·`text.*`)으로만 참조하고, 시맨틱 토큰은 Primitive colors 팔레트를 참조합니다.
테마 교체는 preset에서 이 값을 재정의해 이뤄지며 컴포넌트 코드는 그대로입니다.

## Typography - textStyle

`{name}.{size}-{weight}` 형태의 합성 스타일입니다. 굵기: light `400` · normal `500` · bold `700`.

크기는 `모바일 / 태블릿 / 데스크톱` 순입니다. `heading.*` 전체와 `body.large-*` · `input.medium/small-light`는 반응형으로, tablet(≥768px)부터 데스크톱 크기로 전환됩니다. **태블릿 값은 아직 잠정(미정)이며 현재는 데스크톱과 동일합니다.** 나머지는 모든 브레이크포인트에서 동일합니다.

| textStyle | 모바일 | 태블릿 | 데스크톱 | 굵기 |
| --- | --- | --- | --- | --- |
| `heading.xxlarge-bold` | 4rem | 4.8rem (미정) | 4.8rem | bold |
| `heading.xlarge-bold` | 2.8rem | 4rem (미정) | 4rem | bold |
| `heading.large-bold` | 2.4rem | 4rem (미정) | 4rem | bold |
| `heading.medium-bold` | 1.8rem | 3.2rem (미정) | 3.2rem | bold |
| `heading.small-bold` | 1.6rem | 2rem (미정) | 2rem | bold |
| `body.large-bold` | 1.8rem | 2rem (미정) | 2rem | bold |
| `body.large-normal` | 1.8rem | 2rem (미정) | 2rem | normal |

| `body.medium-bold` | 1.6rem | 1.6rem | 1.6rem | bold |

## Fonts

| 키 | 값 |
| --- | --- |
| `body` | `"Spoqa Han Sans Neo", sans-serif` |

기본 브랜드 폰트는 **Spoqa Han Sans Neo**입니다.
폰트는 직접 로드하거나 아래처럼 `fonts.body`를 재정의해 다른 폰트로 브랜딩합니다.

```ts
import { defineConfig } from '@pandacss/dev';
import { preset } from '@bigmobility/vinyl-ui/preset';

export default defineConfig({
  presets: [preset],
  theme: {
    extend: {
      tokens: {
        fonts: { body: { value: '"Pretendard", sans-serif' } },
      },
    },
  },
});
```
